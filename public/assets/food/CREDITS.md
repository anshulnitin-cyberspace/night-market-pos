# Food images

The dish photos in this folder are supplied by the project author for this demo.

Each file is named after the menu item `id` in `lib/data/menu.ts`: `skewers.jpg`,
`soup-dumplings.jpg`, `herbal-tea.jpg`, and so on. The menu card and cart row use
`object-cover object-center`, so photos of any size are cropped to a square
instead of stretched.
